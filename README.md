# Two Independent Brand Websites

This workspace contains two separate React + Vite frontend projects. Each folder has its own `package.json`, Vite configuration, entry point, components, and styles; the visual systems and page layouts are intentionally independent.

- `nova-tech-website/` — premium, minimalist technology company site.
- `velora-creative-website/` — bold, editorial creative agency site.

## Run either website

Open a terminal in the project folder you want to run, then run `npm install` followed by `npm run dev`. Each project can be installed, developed, built, and deployed independently. Production builds use `npm run build`.

Both forms are frontend demonstrations only; they show an inline confirmation and do not send or store submissions.
