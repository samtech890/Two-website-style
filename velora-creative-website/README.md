# VELORA

An independent React + Vite portfolio site for a bold creative branding and digital agency.

## Run locally

1. Install Node.js 18+.
2. From this folder run `npm install`.
3. Run `npm run dev` and open the local URL Vite prints.
4. Run `npm run build` to create a production build.

The contact form is frontend-only and provides an inline confirmation; connect it to a form provider or API to receive submissions. Photography and fonts load from Unsplash and Google Fonts.
